# Curtain · Velvet Stage

개인용 뮤지컬 음원·영상 아카이브입니다. 작품과 넘버를 한곳에 모아 감상하고, 필요한 기록과 재생 설정을 관리할 수 있습니다.

> 현재 Curtain은 **베타 버전**입니다. 기능과 안정성을 계속 개선하고 있습니다.

## 설치

1. [Releases](https://github.com/rumins0108/Curtain-Releases/releases)에서 가장 최신의 `Curtain-Setup-버전.exe` 파일을 내려받습니다.
2. 설치 파일을 실행하고 안내에 따라 설치합니다.
3. 설치 중 바탕화면 바로가기 생성 여부를 선택할 수 있습니다.

- Windows 10/11 64비트 지원
- 처음 실행할 때 필요한 재생 구성 요소가 준비될 수 있습니다.
- 새 버전이 배포되면 앱 실행 시 알림과 환경설정의 업데이트 영역에서 확인할 수 있습니다.

## 주요 기능

- 로컬 음원·영상과 YouTube 링크를 같은 라이브러리에서 재생
- 작품별 넘버, 배우, 대표 이미지, 작품 설명 관리
- 재생목록, 즐겨찾기, 최근 재생, 자주 듣는 넘버 확인
- 보관함으로 작품 또는 넘버를 숨기고 필요할 때 복원
- 로컬 미디어의 구간 생성·편집과 파형 기반 시작·종료 지점 설정
- YouTube 영상의 재생 구간 설정과 재생목록 가져오기
- 넘버별 가사·대본 기록 및 재생 화면 확인
- 라이트·버건디·다크 테마와 미니 플레이어 지원

## 기본 사용

### 음악과 영상 등록

왼쪽 상단의 **음악 추가**에서 로컬 파일·폴더 또는 YouTube 영상을 선택합니다. YouTube 영상은 링크와 목록에 표시할 제목을 등록하면 되며, 작품명을 비워 두면 작품 목록에 포함되지 않습니다.

### 작품 관리

사이드바의 작품 목록에서 작품을 선택하면 해당 작품의 넘버만 볼 수 있습니다. 제목 또는 작품 수를 눌러 목록을 정렬할 수 있으며, 오른쪽 경계를 드래그하면 사이드바 너비를 조절할 수 있습니다. 작품명을 우클릭하면 이름 수정, 대표 이미지 설정, 작품 설명 편집, 내보내기, 보관, 삭제를 사용할 수 있습니다.

### 보관함과 삭제

보관함으로 이동한 작품·넘버는 일반 목록과 전체 라이브러리에서 숨겨집니다. 보관함에서 언제든 복원할 수 있습니다. 삭제는 Curtain에 저장된 등록 정보만 제거하며 원본 로컬 파일은 삭제하지 않습니다.

### 데이터 관리

환경설정에서 백업 저장·복원과 전체 초기화를 사용할 수 있습니다. 백업에는 개인 설정과 기록이 포함되지만 원본 로컬 미디어 파일은 포함되지 않습니다.

## 저작권 및 이용 안내

- YouTube 콘텐츠는 공식 내장 플레이어로 재생하며 영상·음원을 다운로드하지 않습니다.
- 로컬 파일은 본인이 적법하게 이용할 수 있는 파일만 등록해 주세요.
- Curtain을 이용한 불법 배포·공유는 금지됩니다.
