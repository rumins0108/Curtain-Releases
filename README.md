## Curtain으로 할 수 있는 일

| | 주요 기능 |
| :--- | :--- |
| **음악과 영상을 함께** | 로컬 MP3·MP4와 YouTube 링크를 같은 라이브러리에서 재생하고, 영상은 PiP로 감상합니다. |
| **작품별로 정리** | 작품을 만들고 속폴더로 나누며, 작품 고정과 드래그 순서·수록곡 사용자순을 관리합니다. |
| **원하는 곡 가져오기** | YouTube 제목 검색·링크·재생목록에서 원하는 음원을 골라 여러 곡 가져옵니다. |
| **차트에서 새 음악 찾기** | 멜론 TOP100의 보유 여부를 비교하고, 추천 알림에서 YouTube 인기 차트의 미보유 곡을 확인합니다. |
| **내게 맞게 편집** | 제목·가수/배우·해시태그·구간·음량을 수정하고, 가사/대본에 글자 서식을 적용합니다. |
| **기록과 데이터 관리** | 즐겨찾기·재생 횟수·최근 재생·최근 추가 음원을 확인하고, 작품 공유와 자동 백업을 이용합니다. |

## 1.0.14에서 달라진 점

- **작품 생성과 속폴더** — 작품 목록의 + 버튼으로 기존 음원을 모아 새 작품을 만들고, 한 단계 속폴더로 나눠 관리합니다.
- **작품 수록곡 사용자순** — 제목순과 사용자순을 선택하고, 작품·속폴더별로 드래그한 순서를 저장합니다.
- **해시태그 검색** — 음원에 #태그와 메모를 남기고, 검색창에서 같은 태그로 모아 봅니다.
- **가사/대본 플로팅 창** — 드래그 이동과 고정핀을 지원합니다. 다시 열면 기본 위치로 돌아가며, 다음 곡으로 넘어가면 닫힙니다.
- **다양한 글자 서식** — 더 두꺼운 굵게, 밑줄, 기울임, 테마 글자 강조와 글자색을 유지하는 배경 강조를 제공합니다.
- **간결한 수정 화면** — 구간·음량·가사/대본은 기본으로 접힌 세부설정에서 편집합니다.

[전체 업데이트 내용 보기 →](https://github.com/rumins0108/Curtain-Releases/releases/tag/v1.0.14-beta)

## 기능 자세히 보기

<details>
<summary><strong>작품 생성 · 속폴더 · 고정 · 순서 변경</strong></summary>

- 작품 목록 옆 **+**에서 이름을 입력하고 음원을 1개 이상 선택해 새 상위폴더를 만듭니다. 선택한 음원은 기존 작품·속폴더에서 새 작품으로 이동하며, 음원 정보와 즐겨찾기·재생 횟수는 유지됩니다.
- 상위 작품 아래에 **한 단계 속폴더**를 만듭니다. 기본으로 접혀 있으며, 우클릭으로 펼치거나 닫을 수 있습니다.
- 작품 수록곡은 **제목순 / 사용자순**으로 정렬합니다. 사용자순에서는 드래그로 곡 순서를 바꾸고 작품·속폴더별로 저장합니다.

- 작품명 우클릭에서 **상단에 고정하기 / 상단 고정 해제하기**를 선택합니다. 고정 개수 제한 없이, 최근 고정한 작품부터 압정 표시와 함께 보여줍니다.
- 일반 작품을 드래그하면 순서를 바꿀 수 있고, 다시 실행해도 유지됩니다. 고정 작품은 이동하지 않습니다. **작품명 / 작품 수**를 누르면 해당 기준으로 다시 정렬합니다.
- 작품명 입력칸 오른쪽 **▼**에서 기존 작품·속폴더와 수록 곡 수를 확인하고 선택합니다. 새 이름 직접 입력도 가능합니다.
- 작품 이름을 빈칸으로 저장하면 묶음만 해제되고, 음원은 작품 미지정 상태로 남습니다.

</details>

<details>
<summary><strong>YouTube 검색 · 여러 곡 가져오기 · 재생목록</strong></summary>

- <strong>YouTube (링크/검색)</strong>에서 영상·재생목록 링크를 붙여넣거나 제목으로 검색합니다. YouTube Music 링크도 사용할 수 있습니다.
- 결과 창에서 검색어를 바꾸고 **확인 / Enter**로 재검색합니다. 검색 개수는 기본 **5개**, 설정 범위는 **2~30개**입니다.
- 기본 정렬은 **조회수 높은 순**입니다. 열 머리글을 더블클릭하면 제목·가수/채널은 이름순, 조회수·길이는 높은 순으로 정렬합니다.
- 여러 결과를 체크해 한 번에 가져옵니다. 단일 음원은 **구분하기 / 반대로 구분하기 / 구분하지 않기**로 제목과 가수명을 정리합니다.
- **환경설정 → 화면**에서 한국어(KR)·영어·일본어를 선택합니다. 기본값은 한국어이며, 제공되는 현지화 정보가 없으면 원래 제목·가수 정보를 표시합니다.
- 내 YouTube 재생목록은 Google 계정 연결 후 열 수 있습니다. 미리보기, 검색, 전체 선택, 등록 영상 숨기기와 순번 붙이기를 제공합니다.

</details>

<details>
<summary><strong>멜론 TOP100 · 추천 알림 · 최근 추가 음원</strong></summary>

- 멜론 TOP100과 내 라이브러리를 비교해 **보유 / 확인 필요 / 미보유** 상태를 확인합니다. 체크·전체 선택으로 필요한 곡을 가져오고, 보유곡의 YouTube 연결도 변경할 수 있습니다.
- 추천 알림은 바깥을 클릭하면 닫힙니다. 한국 주간 인기 음악·인기 급상승 음악·일간 쇼츠 인기 음악의 차트를 확인합니다.
- **최근 추가 음원**에서 새로 등록한 곡을 찾습니다. 제목 옆 **NEW**는 등록 후 24시간이 지나거나 음원을 재생하면 사라지며, 음원은 목록에 계속 남습니다.
- 가져오기 완료 후 **추가한 음원 보기**로 이동하고, 상세정보에서 등록 날짜와 출처를 확인합니다.

</details>

<details>
<summary><strong>음원 상세정보 · 구간 · 타임라인</strong></summary>

- 음원을 우클릭한 뒤 **수정하기**에서 제목, 가수/배우명, 작품명, 링크·파일 경로, 해시태그·메모를 편집합니다.
- **세부설정**을 펼쳐 구간 시작·종료, 음량 보정, 가사/대본을 수정합니다.
- `#2022작품`, `#2026공연`처럼 태그를 남긴 뒤 검색창에서 같은 태그를 검색합니다.
- 저장 전 기존 내용과 변경 내용을 확인합니다. 상세정보에서 링크를 바꾸면 기존 음원에 반영하며, 즐겨찾기와 재생 횟수는 유지합니다.
- 긴 YouTube 영상의 시간표를 **타임라인 등록**에 붙여넣어 구간별 음원으로 등록합니다.
- 로컬 음원도 구간을 설정하고, 음원별 음량을 보정할 수 있습니다.

</details>

<details>
<summary><strong>가사/대본 · 이동과 고정 · 글자 서식</strong></summary>

- 재생바 위 **가사/대본**을 눌러 창을 엽니다. 상단을 드래그해 옮길 수 있고, 다시 열면 기본 위치로 돌아옵니다.
- **고정핀**을 켜면 바깥을 눌러도 유지됩니다. X로 닫거나 다음 곡으로 넘어가면 닫힙니다.
- 가사/대본이 없으면 안내와 함께 편집창을 엽니다. **음원 우클릭 → 수정하기 → 세부설정**에서도 같은 편집창을 이용합니다.
- 글자를 선택해 **굵게·밑줄·기울임·테마 강조·배경 강조**를 적용합니다. 같은 버튼을 다시 누르면 해당 서식을 해제합니다.
- 배경 강조는 테마 강조색을 옅게 적용하며 **글자색은 유지**합니다. 저장한 서식은 표시 창에도 반영됩니다.

</details>

<details>
<summary><strong>테마 · 목록 설정 · 백업과 공유</strong></summary>

- 라이트·버건디·다크·미드나이트 블루·체리 블라썸·포레스트 그린의 **6가지 테마**를 제공합니다.
- 목록 간격을 바꾸고, 열 머리글 우클릭 또는 **환경설정 → 화면**에서 열 넓이를 한 번에 조절합니다. 설정은 다시 실행해도 유지됩니다.
- 자동 백업과 복원, 라이브러리 상태 점검, 누락된 로컬 파일 다시 연결을 지원합니다.
- 작품을 작품 파일(`.curtain`)로 내보내 다른 Curtain 라이브러리에서 불러올 수 있습니다.

</details>

<details>
<summary><strong>열 필터 · 상태 표시 · 재생과 음량</strong></summary>

- 여섯 라이브러리 화면의 음원·작품·배우·상태 머리글에서 ▼를 눌러 항목을 검색하고 선택합니다. 기본값은 전체 선택입니다.
- **Esc / 바깥 클릭**은 적용하지 않고 닫기, **기본 정렬로 되돌리기**는 현재 화면의 정렬·필터를 함께 초기화합니다.
- 상태는 **유튜브·로컬영상·로컬음원**과 각각의 **(구간)**으로 표시합니다. 길이·재생 횟수는 표시와 정렬을 제공합니다.
- 재생바·볼륨바는 원하는 위치를 클릭해 조절하고, 스피커는 음소거/이전 볼륨 복원으로 사용합니다.
- **음원 추가하기**에서 유튜브 (링크/검색), 로컬 파일 불러오기, 문서 불러오기를 선택합니다.

</details>

## 이용 안내

<details>
<summary><strong>Google 계정 연결이 필요한가요?</strong></summary>

일반 YouTube 검색·링크 등록과 로컬 라이브러리는 계정 연결 없이 사용할 수 있습니다. 계정 연결은 **내 YouTube 재생목록 열람·가져오기**에 사용합니다.

현재 Google 검증 전 테스트 상태로, 등록된 테스트 계정에서 연결할 수 있습니다. Google 연결이 YouTube Music의 로그인 검색 결과를 가져오는 기능은 아닙니다.

**나중에 볼 동영상**은 YouTube 웹 바로가기이며, YouTube Music 보관함 전체 동기화는 지원하지 않습니다.

</details>

<details>
<summary><strong>YouTube 음원을 파일로 다운로드하나요?</strong></summary>

YouTube 콘텐츠는 공식 내장 플레이어로 재생합니다. 영상·음원을 파일로 다운로드하지 않습니다. 이용할 수 없거나 재생이 제한된 영상은 가져오기·재생이 어려울 수 있습니다.

로컬 파일과 공유 자료는 이용 권한이 있는 콘텐츠만 사용해 주세요. Curtain을 이용한 불법 배포·공유는 금지됩니다.

</details>
